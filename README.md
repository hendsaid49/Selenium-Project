# Selenium Basics Project 🚀

This repository contains my first automation project using **Java** and **Selenium WebDriver**. 
It covers fundamental browser actions essential for any **Software Quality Assurance (QA)** professional.

## 🛠 Features Covered:
*   **Navigation:** Handling `back()`, `forward()`, and `refresh()` commands.
*   **Window Management:** Automating window sizing, positioning, and maximizing.
*   **Multi-Tab Handling:** Switching between tabs and new windows using `WindowHandles`.

## 📦 Tech Stack:
*   **Language:** Java
*   **Tool:** Selenium WebDriver
*   **Build System:** Maven (pom.xml included)
*   **Alerts Automation:** Handled JavaScript alerts and confirmations using Selenium WebDriver.
## 🛠️ Key Technical Implementations
* **Advanced Relative Locators (Selenium 4):** Implemented Friendly/Relative Locators (`above`, `below`) to find elements dynamically based on their visual position on the page (e.g., locating input fields relative to each other).
* **Locators Used:** Handled complex and dynamic web elements using highly stable and optimized **CSS Selectors** and **XPath**.
* **Dynamic Elements Handling:** Successfully managed dynamic fields like Facebook's Gender dropdowns and registration input fields.
* **Test Verification:** Validated the continuous flow of user data entry including Name, Date of Birth, Email, and Password.
